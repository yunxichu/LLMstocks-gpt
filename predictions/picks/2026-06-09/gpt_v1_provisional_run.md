## 1. 运行状态与证据等级

### 1.1 为什么本轮不是 `research_grade`

按仓库新增规则，研报级目标价需要：

- 最近 90 天 3-5 个可信研报/一致预期输入。
- 完整 EPS / 净利预测桥。
- 主估值法 + 交叉验证。
- 外部目标价高/中/均/低与自己的 base/bull/bear。
- 上修/下修触发器。

本轮没有 Wind / Choice / FactSet / LSEG I/B/E/S / Bloomberg 授权数据库，也没有完整读取所有付费研报全文。因此：

- 财报、公告、官方行业数据：`hard`
- yfinance analyst target / recommendation：`soft consensus proxy`
- 公开研报摘要、财经站转载研报元数据：`soft` 或 `pending_verify`
- 结论状态：`provisional`

这比上一版更严格：**不再把 yfinance 目标价或 PE 简算当作正式研报级估值，只把它们作为交叉校验。**

### 1.2 本轮选择的样本

正向候选：

- 宁德时代：新能源车 / 储能 / 全球电池龙头。
- 思源电气：电网设备 / 海外电力设备 / 数据中心供电。
- 工业富联：AI 服务器 / 算力基础设施。
- 金山办公：AI 办公 / 国产软件 / 订阅。
- 中微公司：国产半导体设备 / 刻蚀 / 薄膜 / 平台化。

回避候选：

- 中际旭创、新易盛：光模块基本面强，但估值和涨幅拥挤。
- 寒武纪：国产 AI 芯片弹性强，但估值过热。

## 2. 市场与产业链逻辑

### 2.1 AI 基建需求仍是主线，但不能无差别追高

证据：

- NVIDIA FY2027 Q1 披露，Data Center 相关收入继续高增，AI 基础设施需求没有明显熄火。
- Microsoft FY2026 Q2 披露，Microsoft Cloud 收入 515 亿美元，同比 +26%；Azure 和其他云服务收入同比 +39%，说明云厂商 AI 基建投入仍强。
- SEMI World Fab Forecast 1Q26 更新预计 2026 年全球设备支出继续增长，中国仍是全球最大支出市场之一。

逻辑：

```text
云厂商 AI capex 增长
→ AI 服务器 / 交换机 / PCB / 光模块 / 数据中心供电需求增长
→ 服务器代工、功率设备、半导体设备受益
→ 但光模块和部分 AI 芯片标的已经把高增长提前定价
```

因此，**同样受益 AI，优先看估值没有极端透支的环节：工业富联、思源电气、中微公司；回避短线过度拥挤的光模块和寒武纪。**

### 2.2 总需求一般，结构性制造业仍强

证据：

- NBS 2026 年 5 月制造业 PMI 为 50.0，处于荣枯线；但高技术制造业 PMI 52.9，装备制造业 PMI 52.1。

逻辑：

```text
总需求不是全面牛市
→ 不能买所有周期/制造
→ 只买有结构性订单、产业链地位、利润兑现的公司
```

### 2.3 新能源不是全面反转，只选全球龙头和订单能见度强者

证据：

- 宁德时代 2026 Q1 营收 1291.31 亿元，同比 +52.45%；归母净利润 207.38 亿元，同比 +48.52%；经营现金流 336.81 亿元。
- 宁德时代投资者关系记录显示动力和储能合计销量超过 200GWh，储能占比约 25%。
- CATL 官方年报新闻稿引用 SNE Research：2025 年全球动力电池份额 39.2%，储能电池份额 30.4%。

逻辑：

```text
国内新能源链仍有价格战
→ 二三线材料/设备容易受压
→ 但宁德时代的全球份额、现金流和储能占比提升能抵消部分周期压力
```

### 4.1 宁德时代 `300750.SZ`

**判断：BUY。12M 基础目标 555 元，区间 530-580 元。**

#### 财报锚

- 2026 Q1 营业收入 1291.31 亿元，同比 +52.45%。

- 2026 Q1 经营现金流 336.81 亿元，同比 +2.47%。
- 基本 EPS 4.58 元，同比 +44.03%。

证据等级：`hard`，来源为公司一季报。

#### 产业链逻辑

```text
动力电池全球份额强
+ 储能电池占比提升
+ 海外高价值市场扩张
→ 规模和成本优势继续体现
→ 价格战压力可被份额和储能结构改善部分抵消
```

#### 公开研报 / 一致预期矩阵

状态：`partial`

| 来源 | 日期 | 评级/动作 | 预测/目标 | 证据等级 |
|---|---|---|---|---|
| 花旗研报转载 | 2026-06-08 | 维持买入，H 股目标价上调至 888 港元 | 2026-2028 盈利预测上调至 1030/1260/1490 亿元 | `soft`，财经媒体转载 |

| yfinance analyst proxy | 2026-06-09 抓取 | strong_buy | 23 家，目标均值 556.41，中位 550 | `soft consensus proxy` |

#### 估值计算

```text
当前价 = 393.02
forward PE = 16.28
yfinance implied FY2026 EPS = 393.02 / 16.28 = 24.14

财报校验：
Q1 EPS = 4.58
若全年 EPS = 22-25，需后续三个季度合计 EPS 17.4-20.4；
考虑 Q1 同比 +44% 和储能占比提升，24.14 元作为基础 EPS 可接受。

合理 PE：
bear = 20x（价格战/海外折价）
base = 23x（全球龙头 + ROE 25% + 份额优势）
bull = 26x（储能高毛利和海外订单继续上修）

base target = 24.14 × 23 = 555
range = 24.14 × 22-24 = 531-579
```

#### 为什么是 BUY

- 财报兑现强，不是只靠题材。
- 外部目标价代理与内部模型接近。
- 现价到基础目标约 +41%，大于 15% 的最低 BUY 空间。
- 估值不是极端高估，forward PE 16.28 对全球龙头并不贵。

#### 下修条件

- 储能毛利率被价格战快速压低。
- 海外政策/关税影响出货。
- FY2026 EPS 低于 22 元，则基础目标降到 480-510。

### 5.1 中际旭创 `300308.SZ`

**判断：AVOID / 不追高。合理区间 970-1150 元。**

公司基本面并不差，甚至很强：

- yfinance 显示收入增速 192.1%，利润增速 259.4%，ROE 53.93%。
- 2026 Q1 报告显示基本 EPS 5.18 元，说明业绩确实兑现。

问题在价格：

```text
当前价 = 1154.99
60 日涨幅 = +119.58%
forward PE = 26.00
implied FY2026 EPS = 44.42
yfinance target mean = 914.43
yfinance target median = 1016

合理 PE = 22-26x
fair range = 44.42 × 22-26 = 977-1155
```

逻辑：

- 当前价已经在合理区间上沿。
- 外部目标均值低于现价。
- 光模块景气若继续超预期，股价可以继续强，但这已经是动量交易，不是估值有安全边际的买入。

解除 AVOID 的条件：

- 回撤到 950-1000 区间，或
- FY2026 EPS 上修到 50 元以上且订单/毛利率继续强。
