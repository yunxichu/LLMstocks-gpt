## Hard requirements

- 3 类必须各 ≤ 5 支 (不足 5 诚实输出，说明原因)
- **ai_picks**: 每只 `theme` ∈ AI_THEMES, BUY 红旗约束 (0 HIGH + ≤1 MEDIUM)
- **market_picks**: 每只 `theme` ∉ AI_THEMES (或为空表示 watchlist 单独名)
- **ai_picks 与 market_picks 的 ticker 不能重叠** (lock 强制校验)
- **avoid_picks**: ≥1 HIGH 或 ≥2 MEDIUM 红旗，每条带 evidence
- 每只 pick: `red_flags_checked = [1..18]` 全 18 类扫描
- **每只 pick: `evidence_log` ≥ 3 个 type='hard' entries** (v0.7) +
  所有 soft / pending_verify claim 显式标记
- 不允许 "watchlist only / neutral"
- 不能 fabricate; 数据缺失写 open_checks + 降 confidence

## Workflow (v0.8)

Follow `playbooks/weekly_picks.md` Stage 1 → Stage 6:

- **Stage 1**: 候选池 (30-80 tickers from watchlist + themes 50 代表股 +
  美股龙头映射 + 财联社热点)
- **Stage 2**: 批量 yfinance 初评 (fast, no WebFetch)
- **Stage 3**: 短列表 (15-20 tickers, mark each candidate's theme)
- **Stage 4**: WebFetch 每只短列表 → 全 18 类 red flag 扫描
- **Stage 4b** (v0.7): 为每只候选 build `evidence_log` (hard/soft/pending_verify)
- **Stage 5** (v0.8): 三步选择 (顺序很重要！)
  1. **5a: AVOID 5** (任意主题, 高知名度 × 严重度优先)
  2. **5b: AI Picks 5** (limit AI_THEMES, exclude AVOID list tickers)
  3. **5c: Market Picks 5** (non-AI themes, exclude AI + AVOID list tickers)
- **Stage 6**: 输出 YAML + raw.md + Lock + render HTML

## Output

Write **three** files under `predictions/picks/<YYYY-MM-DD>/`:

1. `picks_<HHMMSS>.yaml` — structured 15-name card (per `templates/picks_card.yaml`)
2. `picks_<HHMMSS>.raw.md` — human-readable Markdown report
3. `picks_<HHMMSS>.html` — interactive HTML (generated by `render_picks_html.py`)

picks_id 格式: `picks-<yyyymmdd>-<HHMMSS>`. ISO 8601 with `+08:00` for `analyzed_at`.

## Lock + Render

```powershell
# Lock the YAML (validates 3-list schema + evidence_log + red flags)
python tools/lock_picks.py predictions/picks/<YYYY-MM-DD>/picks_<HHMMSS>.yaml

# After lock succeeds, render the interactive HTML report
python tools/render_picks_html.py predictions/picks/<YYYY-MM-DD>/picks_<HHMMSS>.yaml
```

`lock_picks.py` REJECTS the file if:
- `ai_picks`/`market_picks`/`avoid_picks` 任一超过 5 支
- `ai_picks` 中任一 ticker 的 `theme` 不在 AI_THEMES
- `market_picks` 中任一 ticker 的 `theme` 在 AI_THEMES
- `ai_picks` 与 `market_picks` ticker 集合相交
- 任一 BUY 类 entry 有 HIGH red flag 或 >1 MEDIUM
- 任一 AVOID 类 entry 不达 ≥1 HIGH 或 ≥2 MEDIUM
- 任一 entry 的 `evidence_log` < 3 hard entries
- 任一 red_flag_triggered 缺 evidence 字段
- 任一 entry 缺 `red_flags_checked = [1..18]`

`render_picks_html.py` 生成 self-contained HTML（含 inline CSS，零 JS，HTML5 `<details>` 折叠），用户用浏览器打开即可点击展开每只 pick 的详细分析 / 证据链 / 红旗扫描。

## After lock + render
